# Vanguard Light Design — Next.js

Simple white-background design with light blue, soft green and warm neutral accents.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Main files

- `app/layout.js` — SEO and structured data
- `app/page.js` — homepage
- `app/globals.css` — normal CSS
- `components/` — all sections
- `public/images/` — sample visuals

## Replace later

Update the phone, email, location and WhatsApp number in:
- `components/Contact.js`
- `components/WhatsAppButton.js`

Replace the sample SVG files in `public/images/` with real project photos.
